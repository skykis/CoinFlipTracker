# CoinFlipTracker

游戏王 Master Duel 硬币/先后手/决斗胜负统计工具（手动录入，长期记录当天与累计）。

## 安装

```bash
pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

## 界面

三段式布局：标题栏 → 录入区（三组按钮在同一行、等宽对齐，按钮上印着快捷键；备注/日期/保存/撤销在下一行，与按钮列对齐）→ 当天/累计指标卡片 → 状态提示 → 标签页（三张图表 + 记录列表）。
窗口尺寸由内容实际需要自动计算（不小于 900x720），不会被裁切。
配色与字体集中在 `theme.py`，改样式只需改这一个文件；图表颜色也取自同一调色板。

## 录入

- 点击三组按钮：硬币（赢/输）、先后手（先手/后手）、决斗（胜/负），按 Enter 或"保存"。
- 快捷键：1/2 硬币赢/输，3/4 先手/后手，5/6 决斗胜/负，Enter 保存。
  焦点在输入框（备注/日期）内时数字键不触发，避免打字时误改选择。
- 备注框可选（例如对手或卡组），留空则不记录；保存后自动清空。
- 日期框默认当天，可改成过去的日期补录；格式为 YYYY-MM-DD（`2026-1-5` 会归一化为 `2026-01-05`）。

## 纠错与修改

- **记录列表** 标签页：下拉筛选「全部」或某个日期，表格带滚动条，可浏览长期累计的记录。
- 点击一行 → 编辑面板填充该记录，可改硬币/先后手/决斗/备注/日期，点「更新」写回；「删除」删除该记录；「取消」关闭面板。
- **撤销上一条** 按钮删除最近一次录入；`Ctrl+Z` 同样生效，但焦点在文本框内时不触发（防止打字时误删）。
- 在「记录列表」标签页按 Enter 不会保存录入区的内容；选中一行后按 Enter 写回编辑面板的改动。
- 编辑面板的日期不能留空（留空只表示录入区默认当天）。

## 数据

- SQLite 数据库默认位于 `data/duels.db`，可用 `--db` 指定路径。
- 统计：当天与累计的硬币胜率、先手占比、决斗胜率、连串（当前/最长）。
- 图表标签页：
  - **硬币胜率趋势** — 每天硬币胜率随时间的变化（虚线为 50% 参考线）。
  - **每日对数** — 每天记录的对数，用来判断当天样本是否够多、胜率数字是否可信。
  - **逐局趋势** — 每一局的硬币结果（散点）与累计硬币胜率（曲线），看连串和长期走势。
